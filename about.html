About

DarkSoL41

I reverse engineer retro games: I pick apart file formats and code, then build level editors, utilities, ports and remakes.

Why I do this

This is a hobby. I'm a fan of these games and I think they deserve more than a spot in someone's memory. Every editor, port or remake I make is a way to give them a little more life, so that old players keep coming back and new players get to discover them.

What I do

My favourite systems are DOS, the ZX Spectrum, the NES and the Amiga. It usually starts with a disk image or a ROM: I find where the levels and graphics live, work out the format and build a tool that is pleasant to use.

All projects are free and made for fans. They are unofficial and not affiliated with the original developers or publishers. The games themselves are never included: you need your own copy. Some tools embed a few original sprites or tiles so that levels can be drawn the way the game shows them, and each project page says exactly what's in the download. If you are a rights holder and want something changed or removed, message me on Discord and I will do it.

How I work: vibe coding

These projects are vibe-coded. I decide what to build, explore the game in emulators and debuggers, and describe what I find. The code itself, mostly C++ with SDL2 plus Python for tools, is written together with AI models, mostly Claude. Then I test every build against the real game in an emulator or on the original hardware.

  1. Dump the disk image or ROM and study the file layout.
  2. Trace the code in a disassembler and in the emulator's debugger.
  3. Describe the data format and have Claude write a first reader for it.
  4. Grow it into an editor, port or remake, one tested step at a time.
